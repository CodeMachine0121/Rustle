# 片段 — Requirements Brief

## Goal

讓寫作者**打一個 `/` 就叫出常用 Markdown 結構的清單**，挑一個之後整段結構落進文中，游標停在第一個要填的空格上、提示字選取著等人打字；Tab 一路往下填，填完 Tab 就變回縮排。

要打一張表、一個三級標題、一個連結，現在都得自己數井字號、自己排管線符號。這個功能把那些反覆手打的形狀變成**資料**：一個片段一份可以逐項讀出來的清單，隨 App 出貨——與主題同一個做法，讀者只從選單裡挑，不新增、不編輯。

## Requirements

### 片段是資料，不是程式

- 一個片段**一份檔案**，隨 App 出貨。每一份只說兩件事：**這個片段叫什麼名字**，以及**它長什麼樣子**。
- 讀者只從 `/` 選單裡挑。**不新增、不編輯、不重新排序。**
- 有一份片段檔讀不出來時，那一份**不上架**——不出現在選單裡，而不是插出半段爛掉的 Markdown。其他片段照常可用。
- 一份片段不認識另一份。加一個片段永遠不必動到已經在的任何一份。

### 這次出貨哪些片段

| 名字 | 落下來的形狀 |
| :--- | :--- |
| `H1`～`H6`（六份） | 一到六個井字號，後面一個要填的標題 |
| `Link` | `[要填的文字](要填的網址)` |
| `Image` | `![要填的說明](要填的路徑)` |
| `Table` | 兩欄，一列表頭加一列內容，四個格子都是要填的 |

九份，不多不少。

### template 裡的挖空

- 片段裡用**雙大括號**框起來的地方就是要填的空格。括號裡的字是**那個空格的名字**，寫給讀片段檔的人看的。
- 落進文中的那一刻，**大括號連同裡面的字一起消失**——空格是空的，游標停在那裡，直接打字就是了。畫面上只有一個細記號標出「這裡要填」。
- **不填就走也可以**：那個空格本來就是空的，走了不會留下任何要清掉的字。
- 同一份片段裡兩個名字一樣的空格是**兩個各自獨立的空格**，填一個不會連動另一個。

> **這一條在交付過程中反轉過。** 原本的決定是「提示字留在畫面上並且被選取住，一打字就整段取代」，理由是多格的表格看得出哪一格要填什麼。改成空的，理由是**不填就走時不會留下要刪的字**——`## 標題文字` 看起來像寫好了，`## ` 看起來就是還沒寫完。

### 怎麼叫出選單

- 打**半形 `/`**，而且 `/` 的**前面是行首或一個空白字元**時，選單出現在游標旁。
- `/` 前面是別的字時**不出現**——打 `https://` 從頭到尾一次都不會閃。
- **程式碼區塊裡不出現。** 那裡的斜線是內容。
- **表格裡不出現。**（*`/prd` 階段回頭確認過：維持不出現。在表格格子裡插連結是常見需求，但「把一張表插進一張表的格子裡」會同時弄壞兩張，而「看游標在哪就給不同的選單」屬於另一個切片。這是刻意的取捨，記在 PRD §7。*）
- **組字中絕不出現。** 注音候選視窗開著時打 `/` 什麼都不發生；打**全形 `／`** 也不發生——那是標點。
- `/` 之後繼續打字會**篩選**：打 `/h` 剩下六個標題，打 `/h2` 只剩一個。**不分大小寫**，`/H2` 與 `/h2` 一樣。
- 選單是**九項全列的一張小清單**，畫在游標下方；游標已經在畫面最下緣、下方放不下時**改畫在游標上方**，九項全部看得見。
- 打到**沒有任何片段符合**時，選單自己消失，打過的字留在文中，什麼都不插入。

### 怎麼選，怎麼取消

- 上下鍵移動，**Enter 或滑鼠點擊**確認。
- **Tab 不確認選單。** Tab 在這個 App 裡只有兩個身分（縮排、跳空格），選單不是其中之一。
- 確認的那一刻，`/` 連同後面打的篩選字**一起消失**，換成那個片段。
- **Esc 關掉選單**，`/h2` 那幾個字**留在文中**——那是讀者打的字，沒有理由被吃掉。

### Tab 的兩個身分

**Tab 做什麼，只看「現在有沒有還沒填完的空格」。**

- **有**：Tab 跳到下一個空格，Shift+Tab 回上一個。
- **沒有**：Tab 就是縮排，與今天一模一樣。
- 在最後一個空格上按 Tab，**空格填完了、狀態結束**；再按一次 Tab 就是縮排。
- **組字中按 Tab 不跳空格**，交給輸入法——與組字中不縮排同一個規矩。

還有什麼會讓「填空格」這件事結束：按 Esc、把游標移到片段外面（點別處或用方向鍵走出去）、換去另一篇文章。結束之後 Tab 立刻回歸縮排，不必再按任何鍵。

### 一次只有一組空格在等

**正在填空格時又叫出第二個片段**（例如在 `H2` 的提示字上打 `/link`），新片段落在游標處，**舊片段剩下的空格就不再是空格了**——提示字留在文中。填完新的**不會回到舊的**。

*（這條 `/clarify` 沒問到，`/prd` 階段補的決定。理由：任何時刻最多一組空格在等，Tab 的兩個身分就不必變成有堆疊的。）*

### Esc 與那條逃脫路徑

今天 Esc 有一份工作：按了它，接下來那一次 Tab 會把焦點移出編輯區（因為 Tab 被縮排吃掉了，只用鍵盤的人需要一條出路）。

- **選單開著、或正在填空格時按 Esc，先收掉眼前這件事，不武裝逃脫路徑。** 收完之後按 Tab 是縮排。
- 再按一次 Esc（此時已經沒有選單也沒有空格）才武裝逃脫路徑，**接下來那一次 Tab 焦點離開編輯區**。
- 沒有選單、沒有空格時，Esc 與 Tab 的行為**一個字都沒有變**。

### 一步 undo

一個片段落進文中，在 undo 歷史裡算**一步**——不管它有幾行、挖了幾個空格。按一次 undo 整段回去，與 Tab 一次縮十行算一步同一個道理。

### 不能弄壞的事

- 落進文中的是**普通的 Markdown 文字**。存檔存的就是它，脫離 Rustle 照樣是同一份 Markdown。
- 照既有規矩觸發自動儲存，預覽面板照常渲染。
- **選單絕不在組字時於游標旁重建畫面。** 這是這個 App 拒絕引入自動完成的原始理由，這個功能不能把它破掉。
- 沒叫出選單、沒在填空格的人，**編輯區的行為與今天完全一樣**——包括 Tab、Shift+Tab、Esc 之後的 Tab。

### 需求文件要跟著改的一條

需求文件的 **FR-7.2** 目前寫：

> Tab **絕不觸發**自動完成、片段展開（snippet）、或任何非縮排行為。

**這條被這個切片改掉了**，改成：

> Tab **絕不觸發**自動完成，也絕不移動焦點。**唯一的例外是片段展開留下的空格**：有還沒填完的空格時，Tab 跳到下一個空格；沒有時，Tab 就是縮排。是否有空格由編輯器自己知道，不由設定決定。

寫下來是因為這是需求的單一真實來源，而不是一句可以口頭放過的話。FR-7.1（絕不移動焦點）、FR-7.5（一次算一步 undo）、FR-7.6（組字中不縮排）、FR-7.7（Esc 逃脫路徑）**四條全部維持**，這個功能沒有動到它們。

### 一個假設，請一併核對

片段落下來的提示字（「標題文字」、「要填的網址」）**是文件內容，不是介面文字**——它不隨介面語言切換而改變，因為它會被存進 `.md` 檔。出貨版本的提示字**用中文**。若你希望它跟著介面語言走，那是另一件事（而且會讓同一份檔案在不同語言下長得不一樣），告訴我。

## Out of Scope

- **讀者自製片段。** 這個切片只交出「從選單裡挑一份隨 App 出貨的片段」。讀者自己寫一份放進 vault、或與別人交換片段，留給後續切片——與主題那個切片同一個處境。
- **程式碼區塊、引言、待辦清單片段。** 這次只出九份（標題、連結、圖片、表格）。要加是後面的事，而且加一份不必動到既有的任何一份。
- **多種尺寸的表格。** `Table` 只有一份形狀（兩欄、表頭加一列）。不夠自己接著打。
- **同名空格連動。** 同一份片段裡兩個一樣的名字是兩個獨立的空格。
- **看游標在哪就給不同建議。** 選單永遠是同一份清單（除了程式碼區塊與表格裡根本不出現）。「在表格裡只給表格相關的片段」這種語法感知不做。
- **語法上色、程式碼摺疊、結構大綱。** 這些是「編輯器看懂 Markdown 結構」的另一件事，與這個切片無關，要做請開新切片。
- **`/` 以外的叫出方式。** 沒有工具列按鈕、沒有右鍵選單、沒有另一組鍵盤快捷鍵。
- **模糊搜尋與說明文字。** 選單用名字前綴篩選，不做模糊比對、不在每一項旁邊寫一段解釋。
- **片段的設定項。** 設定面板不多任何一列。要不要用這個功能，由「有沒有打 `/`」決定。
- **貼上圖片。** 已經有自己的功能。`Image` 片段是手打路徑用的，兩者不互相取代。
- **提示字跟著介面語言變。** 提示字是文件內容，不是介面文字。
