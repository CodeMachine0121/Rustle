# Vim 與系統剪貼簿相通 — 需求共識

- **切片**：`feature/vim-clipboard-shares-the-system-clipboard`
- **日期**：2026-09-08
- **狀態**：需求已共識，可進 `/prd`

---

## Goal

開著 Vim 模式時，**Vim 的剪貼簿與作業系統的剪貼簿是同一個剪貼簿**。

今天用 Vim 的按鍵複製走的文字，只留在寫作區內部——切到瀏覽器、通訊軟體或任何其他 App 按貼上，什麼都沒有。反過來，在瀏覽器複製一段字回到寫作區按 Vim 的貼上鍵，貼出來的是寫作區內部上一次留下的舊東西，不是剛剛複製的那一段。這兩件事都讓寫作者必須記住「我剛才是用哪一套鍵複製的」，而那不是寫作者該記的事。

這個切片讓兩邊變成一邊：**Vim 複製或刪掉的文字，別的 App 立刻貼得到；別的 App 複製的文字，Vim 的貼上鍵立刻貼得進來。** 寫作者只要記一件事——複製就是複製，不分哪一套鍵。

---

## Requirements

### 一、Vim 複製或刪掉的文字，其他 App 貼得到

- 用 Vim 的複製鍵複製走的文字，**當下就進系統剪貼簿**。整行複製也一樣，連換行一起。
- **刪掉的文字也算複製。** 在 Vim 的語言裡「刪除」本來就是「剪下」——刪一整行、刪一個字元、改寫一段，被拿走的文字都進系統剪貼簿。
- **存進具名暫存格的也送。** 寫作者要求把文字放進哪一格是他自己的事，但系統剪貼簿一律跟著更新到最後一次複製的內容。
- **唯一的例外是垃圾桶暫存格。** Vim 有一格專門用來「刪掉但什麼都不要留」，用它刪東西時**系統剪貼簿原封不動**——連現有的內容都不能被動到。它存在的意義就是不留痕跡，送出去等於毀掉它。

### 二、其他 App 複製的文字，Vim 的貼上鍵貼得進來

- 在任何其他 App 複製一段文字，回到寫作區按 Vim 的貼上鍵，貼出來的就是**那一段**。
- **最後一次複製的贏。** 先在寫作區用 Vim 複製了一段，接著去別的 App 複製了另一段，回來貼上，貼出來的是別的 App 那一段。
- **具名暫存格不讀系統剪貼簿。** 從某個具名暫存格貼上時，拿到的是那一格自己的內容。具名暫存格的用途就是「放旁邊、別被蓋掉」，讓它們全部讀同一份系統剪貼簿等於讓它們全部消失。
- 系統剪貼簿**空的時候**按 Vim 的貼上鍵，什麼都不做，文章不變。
- 系統剪貼簿**只有一張圖片、沒有文字**時按 Vim 的貼上鍵，什麼都不做。要把圖片貼進文章的方式與今天完全相同，一個字都沒改。

### 三、Vim 模式關著的時候，一切照舊

- 標準的複製、剪下、貼上在任何時候都照今天的樣子，這個切片一個字都沒改到。
- 貼上圖片的行為在 Vim 模式開與關之下**都照今天**。

### 四、沒有新的設定

- 這個相通行為**跟著 Vim 模式一起開關**，不是另一個可以獨立開關的選項。設定畫面不多任何一項。
- Vim 模式本身是每個 Vault 各記一份的既有設定，所以這個行為自然也是——但那是既有設定的結果，不是這個切片新定的規則。

## Out of Scope

- **圖片。** 系統剪貼簿上的圖片一律不由 Vim 的貼上鍵處理；把圖片貼進文章的方式與今天完全相同。
- **快捷鍵總覽那張表。** 既有規則是「Vim 的按鍵不列進去」，這個切片沒有推翻它的理由，也沒有新增任何這個 App 自己教的鍵。
- **新的設定項。** 相通行為跟著 Vim 模式一起開關。
- **Vim 的指令列與搜尋。** 沿用上一個切片的範圍決定，本切片不碰。
- **跨裝置的剪貼簿。** 只談這台機器上的系統剪貼簿。

---

## Open Decisions

給 PRD 作者決定的事：

- **「什麼都不做」的可見程度。** 系統剪貼簿是空的、或只有圖片時按 Vim 的貼上鍵，本共識只說「文章不變」。要不要另外給寫作者任何提示（例如狀態列閃一下），本共識刻意沒決定——傾向不給，因為 Vim 本身在這種情況也是安靜的。
- **複製走的內容是「整行」還是「一段」這件事要不要跟著出去。** Vim 內部會記得複製的是整行還是一段，貼上時行為不同。送到系統剪貼簿之後這個資訊沒地方放（系統剪貼簿只有文字）。回到寫作區用 Vim 貼上時，是否仍能還原「整行」的貼法，由 PRD 明確定義期待。

## Context / Background

- 上一個切片（`feature/vim-mode`）已經交付 Vim 模式本身：三個模式、模式指示、以及「既有快速鍵一律優先」這條硬承諾。本切片建立在它之上，不改它任何一條。
- 既有規則「還原、重做、剪下、複製、貼上是機器教的，不是這個 App 教的」說明標準的複製貼上今天本來就通系統剪貼簿。本切片要補的，正是 Vim 那一套鍵沒有享受到同一件事。
- 「剪貼簿」一詞在本專案已有用例（貼上圖片切片），指的一律是這台機器上的系統剪貼簿；本切片沿用，不另立同義詞。
- 澄清過程中出現一個原本沒拆開的矛盾：「所有暫存格都送出去」與「雙向相通」合起來會讓所有具名暫存格貼上時拿到同一份內容，等於讓具名暫存格全部消失。決議是**出去全送、進來只有預設那一格讀系統剪貼簿**。
