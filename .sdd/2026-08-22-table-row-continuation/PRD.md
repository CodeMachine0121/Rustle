## 1. Background & Goal

### Problem Statement

一張 Markdown 表格的每一列形狀都一樣，而寫作者得**每一列重打一次**：`|`、空白、`|`、空白、`|`，欄數還要自己數對。`/table` 片段解決了第一列，第二列之後又回到手打。

### Expected Outcome

- 在一列表格列的末尾按 Enter，**下一列的直線自動出現**，欄數與上一列相同，游標停在第一格。
- **兩次 Enter 離開表格**：在一列還沒填任何東西的表格列上按 Enter，那一列消失，游標落到表格下方。
- **不在表格裡的 Enter 一個字都沒有變。**

### Out of Scope

- 對齊欄寬、自動補破折號那一列、Tab 在表格裡跳格、刪列／移動列／排序、表格以外的續行。理由見 BRIEF。

---

## 2. User Personas

- **Primary Role:** 寫作者——Rustle 唯一的使用者角色。
- **Usage Context:** 寫作途中，一次填一列表格。**與組字同時發生**：Enter 正是注音的選字鍵，所以這個功能與輸入法搶的是同一顆鍵。

## 3. User Stories & Acceptance Criteria

### US-01 — 下一列自動出現 [priority: P0]

**As a** 寫作者，**I want** 按 Enter 就有下一列，**so that** 我不必每一列重數一次欄數。

```gherkin
Scenario: 兩欄的表格續下一列
  Given 游標在「| 甲 | 乙 |」這一列的末尾
  When 寫作者按 Enter
  Then 下一行是「|  |  |」
  And 游標停在第一格裡

Scenario: 三欄的表格續下一列
  Given 游標在「| 甲 | 乙 | 丙 |」這一列的末尾
  When 寫作者按 Enter
  Then 下一行是三欄的空列「|  |  |  |」

Scenario: 破折號那一列也是表格列
  Given 游標在「| --- | --- |」這一列的末尾
  When 寫作者按 Enter
  Then 下一行是「|  |  |」

Scenario: 整列縮排的表格，下一列跟著縮排
  Given 游標在「  | 甲 | 乙 |」這一列的末尾，該列前面有兩個空白
  When 寫作者按 Enter
  Then 下一行是「  |  |  |」，與上一列對齊

Scenario: 引言裡的表格，下一列保留引言符號
  Given 游標在「> | 甲 | 乙 |」這一列的末尾
  When 寫作者按 Enter
  Then 下一行是「> |  |  |」

Scenario: 游標在列中間時 Enter 沒有變
  Given 游標在「| 甲 | 乙 |」的「甲」後面
  When 寫作者按 Enter
  Then 那一列在游標處被切成兩行，與這個功能上線前一模一樣
  And 沒有補出任何一列

Scenario: 一行普通文字的 Enter 沒有變
  Given 游標在「最近在選桌面框架」這一行的末尾
  When 寫作者按 Enter
  Then 多出一個空行，沒有補出任何表格列
```

### US-02 — 兩次 Enter 離開表格 [priority: P0]

**As a** 寫作者，**I want** 空的一列再按一次 Enter 就離開表格，**so that** 我不會被自動補列困在表格裡。

```gherkin
Scenario: 空的表格列上按 Enter 就離開
  Given 游標在「|  |  |」這一列的末尾，該列每一格都是空的
  When 寫作者按 Enter
  Then 那一列整列消失
  And 游標落在表格下方的空行上

Scenario: 補一列，不填，再按一次就出來了
  Given 游標在「| 甲 | 乙 |」的末尾
  When 寫作者按 Enter，接著再按一次 Enter
  Then 正文只剩「| 甲 | 乙 |」與它下方的一個空行
  And 游標在那個空行上

Scenario: 只有一格空著不算寫完
  Given 游標在「| 甲 |  |」這一列的末尾
  When 寫作者按 Enter
  Then 下一行是「|  |  |」
  And 那一列沒有消失
```

### US-03 — 不弄壞既有的任何一件事 [priority: P0]

**As a** 寫作者，**I want** 這個功能只在表格裡出現，**so that** 我原本的每一個按鍵都還在。

```gherkin
Scenario: 組字中的 Enter 屬於輸入法
  Given 游標在一列表格列的末尾，而寫作者正在用注音組字、候選視窗開著
  When 寫作者按 Enter
  Then 沒有補出任何一列
  And 正文一個字元都沒有變

Scenario: 片段選單與表格續列不可能同時發生
  Given 游標在一列表格列的末尾
  When 寫作者打半形斜線
  Then 片段選單沒有出現——表格列裡不開選單
  And 所以 Enter 在這裡只有一個意思：補下一列

Scenario: 片段選單開著時 Enter 仍然屬於選單
  Given 游標在一行普通文字的末尾，寫作者打了「/h2」，片段選單開著
  When 寫作者按 Enter
  Then 選中的那一份片段落進正文
  And 沒有補出任何表格列

Scenario: 一次補列算一步 undo
  Given 寫作者剛按 Enter 補出一列
  When 寫作者按一次 undo
  Then 那一列一次消失，正文回到按 Enter 之前

Scenario: 補出來的是普通 Markdown
  Given 寫作者用 Enter 補了兩列並填完
  When 寫作者看預覽面板
  Then 預覽把它渲染成一張表
```

## 4. Business Flow & Logic

### 核心規則

| # | 規則 |
| :--- | :--- |
| R-1 | **只有游標在表格列的末尾時才作用。** 列中間、非表格列，Enter 都是原本的 Enter |
| R-2 | 表格列的認定：**行首（允許空白與 `>`）之後第一個字元是 `\|`**。與片段選單「表格裡不觸發」用的是同一條判斷 |
| R-3 | 補出來的列**欄數與當前列相同**，每一格都是空的，並**保留當前列的行首**（縮排與引言符號） |
| R-4 | **當前列每一格都是空的時，Enter 移除整列並離開表格。** 這是唯一的出口 |
| R-5 | **組字中一律不作用。** Enter 是注音的選字鍵 |
| R-6 | 片段選單開著時，Enter 屬於選單（它在更高的優先權上）。**兩者實際上不可能在同一個位置爭 Enter**——選單在表格列裡不開——但優先權仍然明確排好，因為「不可能」是另一個功能的規則，不該由這裡假設 |
| R-7 | 一次補列或一次移除算**一步** undo |

### 邊界與例外

| 情況 | 行為 |
| :--- | :--- |
| 游標在列末尾，但列裡只有一個 `\|`（例如 `\|`） | 視為一欄的表格列，補一列 `\|  \|`。不特別處理——那是寫作者打了一半的表格 |
| 只有一格是空的 | 照樣補列。整列都空才算寫完 |
| 表格列在文件最後一行 | 照樣補列，正文長出一行 |
| 有選取範圍 | 不作用，Enter 是原本的 Enter（取代選取內容） |

## 5. UI/UX Design & Interaction

**沒有設計稿**，也沒有任何畫面元素。這個功能只有一顆鍵、只在表格裡、沒有提示、沒有設定。

| 項目 | 決定 |
| :--- | :--- |
| 游標落點 | 新列的**第一格裡**（`\| ` 之後），不是列首也不是列尾 |
| 空白格 | 每一格是一個空白（`\|  \|`），與 `/table` 片段落下的形狀一致 |
| 設定 | **不新增任何一項。** 要不要用它由「你在不在表格裡」決定 |

---

## 6. Non-Functional Requirements

| 面向 | 要求 |
| :--- | :--- |
| **輸入法（產品第一主張）** | 組字中按 Enter **不得動文件**。這一條比其他功能嚴格：Enter 是注音的選字鍵，動了文件就是把寫作者正在選的字吃掉 |
| **undo 完整性** | 一次補列、一次移除各算一步 |
| **不倒退** | 不在表格列末尾時，Enter 的行為**逐項與上線前相同** |
| **反應速度** | 只讀當前一行的文字，不查語法樹、不讀檔 |
| **追蹤／分析** | 無 |

## 7. Dependencies & Risks

### 外部依賴

無新增。用的是編輯器既有的按鍵綁定機制。

### 已知風險

| 風險 | 說明與對策 |
| :--- | :--- |
| **Enter 是這個 App 第三個被搶的鍵** | Tab（縮排／跳挖空）、Esc（三層）之後是 Enter。這一顆的優先權必須在**片段選單之下、編輯器預設之上**——選單的 Enter 在最高優先權，而預設的 Enter 換行在預設優先權，所以這個功能落在中間那一層。放錯任何一邊都會壞掉，而症狀都是「Enter 沒反應」而不是錯誤 |
| **把人關在表格裡** | 若「空列離開」那條沒做對，每一次 Enter 都補一列，寫作者出不了表格。**這是這個功能最嚴重的失敗模式**，US-02 三條情境全部為它而寫 |
| **判斷用行首 `\|` 而不是語法樹** | 編輯器跑 CommonMark，語法樹裡沒有表格節點。代價是「一行剛好以 `\|` 開頭但不是表格」也會補列——那種行在 Markdown 裡幾乎只可能是表格 |
