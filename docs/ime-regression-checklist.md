# 輸入法回歸清單（人工）

這 13 項是**決定人工執行**，不是「尚未自動化」。

程式驅動的合成組字事件走的是渲染引擎的組字路徑，不會叫出任何真的輸入法、也不會畫出候選視窗；而這份清單要驗的正是「真實輸入法在真實候選視窗下的行為」。一個不叫出輸入法就綠燈的測試，會讓人以為這件事被守住了。能誠實自動化的部分（組字中暫停計時、編輯區回報組字狀態）已經是單元測試：`src/shared/composition/`、`src/features/editor/`。

## 什麼時候要跑

- 功能大致完成後，由使用者親手跑一輪。
- **升級 Tauri（含 `tauri`、`tauri-build`、`@tauri-apps/*`、`wry`）或 CodeMirror（任何 `@codemirror/*`）之前與之後**：全部 13 項重跑。見文末「發佈檢查清單」。
- 動到編輯區、組字狀態、去抖動器、焦點切換的 PR：至少重跑相關項目。
- **新增或修改任何接 `Cmd+V`／paste 事件的處理（例如貼上圖片）**：全部 13 項重跑，外加在組字中按 `Cmd+V`，候選視窗與組字中的字都不能被打斷、正文不能多出任何東西。
- **新增或修改任何接 `Cmd+B`／`Cmd+I` 的處理（粗體與斜體）**：全部 13 項重跑，外加在組字中（候選視窗開著）各按一次 `Cmd+B` 與 `Cmd+I`：正文一個字元都不變、候選視窗還開著、沒有任何東西被選起來；選完字後再按，才變粗體或斜體。

- **新增或修改任何接 `Cmd+W` 的處理（逐層擴大選取）或 App 選單**：全部 13 項重跑，外加在組字中（候選視窗開著）按一次 `Cmd+W`：正文不變、候選視窗還開著、選取沒有變、視窗沒有關。另在文章清單、建立文章對話框的標題欄位、預覽區各按一次 `Cmd+W`：視窗都不關；按 `Shift+Cmd+W` 才關（有未存修改時先存完）；選單「File」與「Window」裡的 Close Window 旁標示 `⇧⌘W`，Undo、Redo、Cut、Copy、Paste、Select All、Minimize、Zoom、Toggle Full Screen、Quit 照舊。

- **新增或修改任何接 `/`、片段選單、挖空或 `Esc` 的處理（片段）**：全部 13 項重跑，T-13 逐條跑完。

- **新增或修改 Vim 模式（`@replit/codemirror-vim` 或它在編輯區的按鍵順序）**：在設定裡打開 Vim 模式，全部 13 項在 Insert 模式（按 `i`）重跑，外加：Insert 模式組字中按 `Esc`，只取消組字、狀態列仍是 `INSERT`，再按一次 `Esc` 才變 `NORMAL`；Normal 模式下切到注音打字（避開會進 Insert 的鍵），按空白或 `Enter` 後正文沒有留下組出來的字；Normal 模式下 `Shift+Cmd+K`、`Option+↑`、`Cmd+/`、`Cmd+Enter`、`Ctrl+H`、`Ctrl+D` 正文一字不變；Normal 模式下 `Tab` 縮排、Normal 模式按 `Esc` 再按 `Tab` 仍是縮排且游標留在編輯區、在表格行按 `Enter` 多一列、`Cmd+B` 加粗、`Cmd+W` 選字且狀態列變 `VISUAL`、`Cmd+0` 字體回預設、`Shift+Cmd+P` 開關預覽；專注模式下 Insert 模式打 `/` 開選單後連按三次 `Esc`：關選單、回 `NORMAL`、離開專注模式。升級這個套件前後也要跑這一條。

## 準備

1. `pnpm install`，然後 `pnpm tauri dev`（或執行已建置的 App）。
2. 輸入法：macOS 內建「注音」為主；T-4 用 macOS 內建「拼音 – 簡體」或「拼音 – 繁體」；T-12 用一套第三方輸入法（例如自然輸入法、RIME）。
3. 每一項從編輯區打開後的乾淨狀態開始；失敗時記下輸入法、macOS 版本、Rustle 的 commit。

### T-1 注音連續輸入一整段

- **怎麼做**：在示範正文最後一行後按 Enter 開新行，用注音連續打「今天天氣很好，我們去公園散步吧。」，中間不停頓，含全形標點。
- **期望**：每個字都落在游標處、順序正確；標點是全形；沒有重複字、沒有漏字、沒有英文字母殘留。
- **失敗**：任何一個字跑位、重複、遺失，或注音符號殘留在文字中。

### T-2 候選視窗貼齊游標（一般行）

- **怎麼做**：在第一個段落中間放游標，打「ㄒㄧㄝˇ」叫出候選視窗。
- **期望**：候選視窗緊貼游標下方（或上方，視螢幕空間），水平位置對齊組字中的文字。
- **失敗**：候選視窗出現在視窗角落、螢幕左上角，或離游標超過一行高。

### T-3 候選視窗貼齊游標（折行處）

- **怎麼做**：在示範正文那一行超長句子的**折行位置**附近（第一行尾端與第二行開頭）各組一次字。把視窗寬度拉窄再試一次。
- **期望**：長行自動折行、沒有橫向捲軸；候選視窗貼著實際顯示游標的那一行；選字後文字留在原位，捲動位置不跳。
- **失敗**：出現橫向捲軸；候選視窗貼到另一行；選字後游標或捲動位置跳走。

### T-4 拼音輸入法

- **怎麼做**：切到拼音，在新行打「xiezuo」選「寫作」，再連續打一句。
- **期望**：同 T-1、T-2；組字中的拉丁字母只以底線組字狀態出現，選字後被正確取代。
- **失敗**：拉丁字母殘留在正文、或選字後文字重複。

### T-5 選字後復原

- **怎麼做**：打一個詞並選字，接著按 `Cmd+Z` 一次。
- **期望**：一次復原拿掉整個剛選的詞（一次組字 = 一步復原）；不會只拿掉半個詞，也不會連前面打好的字一起拿掉。再按 `Cmd+Shift+Z` 恢復。選完字後按 Tab 再按 `Cmd+Z`：只退掉縮排，剛選的詞還在。
- **失敗**：需要按多次才拿掉一個詞；或一次拿掉超過這次組字的內容；或注音符號重新出現。

### T-6 組字中的 Enter

- **怎麼做**：打「ㄏㄠˇ」叫出候選視窗，按 Enter 選字；再按一次 Enter。接著在一列表格列 `| 甲 | 乙 |` 的末尾打「ㄏㄠˇ」，按 Enter 選字；再按一次 Enter。最後在一列空的表格列 `|  |  |` 的末尾組字、按 Enter 選字。再到一個任務項 `- [ ] 買牛奶` 的末尾組字、按 Enter 選字；再按一次 Enter。
- **期望**：第一個 Enter 只屬於輸入法（確定選字），**不**換行；第二個 Enter 才換行。表格列末尾的選字 Enter 不補列、不換行，第二個 Enter 才補出下一列 `|  |  |`；空表格列上的選字 Enter 不會把那一列刪掉。任務項末尾的選字 Enter 不長出新的任務項，第二個 Enter 才長出一個沒有打勾的 `- [ ] `。
- **失敗**：第一個 Enter 同時換行，或選字結果遺失；選字的 Enter 補出一列、刪掉一列、長出一個任務項，或吃掉剛選的字。

### T-7 組字中的 Tab

- **怎麼做**：在清單項目中組字到一半（候選視窗開著）按 Tab，再按 Shift+Tab；選完字後再按一次 Tab。
- **期望**：組字中的 Tab／Shift+Tab 屬於輸入法或被忽略：**不縮排、不退縮**、焦點不離開編輯區、組字中的文字不遺失。選完字後的 Tab 把那一行縮排一級，且一次 `Cmd+Z` 只退掉這次縮排（不連帶退掉剛選的字，對照 T-5）。
- **失敗**：組字中縮排、焦點跳走、組字文字消失。

### T-8 組字停留超過 2 秒

- **怎麼做**：打「ㄒㄧㄝˇ」叫出候選視窗後**停住不動 5 秒**，再選字。
- **期望**：停留期間沒有寫檔（檔案修改時間不變）、預覽不重繪、候選視窗不閃也不關；選完字後，自動儲存才在剩餘時間走完後發生。
- **基準值（今天）**：自動儲存與預覽都已在。開一篇文章、預覽面板開著，停留 5 秒期間預覽的內容不變（選字前打的字不出現在預覽），選完字約 0.15 秒後才出現；候選視窗穩定、選字正常。T-1 ~ T-4、T-12 重跑時也留意預覽開著時候選視窗有沒有延遲。
- **篩選框**：在欄 2 的篩選框打「ㄐㄧˋ」叫出候選視窗後停住 5 秒：清單完全不動；選「技」之後約 0.15 秒才篩一次。
- **失敗**：組字中寫檔或重繪、候選視窗被關掉或閃動、選字結果遺失；篩選框在組字中就把清單篩掉。

### T-9 對話框欄位裡的組字與 Enter

- **怎麼做**：在欄 1 的「新 workspace 名稱」欄位用注音打「筆記」，第一個 Enter 選字，再按一次 Enter。接著在欄 2 按「＋ 新文章」：在 Title 欄位打「台灣」，第一個 Enter 選字、第二個 Enter 送出；再開一次對話框，在 Tags 欄位打一個詞，第一個 Enter 選字、第二個 Enter 成為 chip；組字中按一次 Esc。再對欄 2 某一列按「編輯 metadata」，在 Title、Tags 各做同樣的事（第二個 Enter 在 Title 是儲存）；對欄 1 某一列按「重新命名」，在輸入欄打「筆記」，第一個 Enter 選字、第二個 Enter 改名，組字中按一次 Esc。
- **期望**：組字中的 Enter 一律屬於輸入法：不送出、不建立 workspace、不建立 chip；選完字後再按一次 Enter 才建立 workspace／chip／送出。組字中的 Esc 只取消組字，對話框與重新命名欄位都不關。候選視窗貼齊欄位游標。送出之後游標停在編輯區第一行，可以直接打字。
- **篩選框與分隔線**：在欄 2 的篩選框用注音打「台積電」，第一個 Enter 選字（清單不因這個 Enter 立刻篩），再按一次 Enter 立刻篩；組字中按 Esc 只取消組字，篩選框裡已經打好的字還在；沒在組字時按 Esc 清空篩選、清單全部回來。把焦點移到編輯區與預覽之間的分隔線，組字中按方向鍵不改變寬度。
- **失敗**：選字的 Enter 送出了表單、儲存了 metadata、改了 workspace 的名字、建立了只有注音符號的 workspace 或 chip、或用注音符號篩了清單；組字中的 Esc 關掉了對話框或重新命名欄位；送出後還要再點一下編輯區才能打字。

### T-10 取消組字與組字中刪除

- **怎麼做**：打「ㄋㄧˇ ㄏㄠˇ」後按 Backspace 數次；再組一次字後按 Esc。
- **期望**：Backspace 只刪組字中的注音符號，不刪到前面已確定的正文；Esc 取消組字、正文不變。
- **失敗**：刪到已確定的文字，或 Esc 後注音符號殘留。

### T-11 組字中切換文章／workspace／關閉視窗

- **怎麼做**：組字到一半時點另一篇文章、另一個 workspace，以及關閉視窗。
- **期望**：先安全結束組字（確定或捨棄，不半途卡住），再切換；原文章沒有寫入注音符號；新文章不會收到上一篇的組字內容；切換之後 Tab 照常縮排；視窗能正常關閉。
- **基準值（今天）**：切換文章、切換 workspace 與關閉視窗都會先等組字結束、存完才離開；關視窗時會先讓編輯區失焦。存不進去時不切換、標題列顯示失敗原因；關視窗第一次不關，第二次一定關。
- **失敗**：組字內容寫進錯的文章、注音符號被存檔、切換後編輯區卡在上一篇、Tab 不再縮排、視窗關不掉。

### T-12 第三方輸入法快速輸入

- **怎麼做**：用一套第三方輸入法，快速連打三句以上（含標點與中英混排，例如「用 Rustle 寫 Markdown。」），在一般行與折行處各做一次。
- **期望**：同 T-1 ~ T-3；中英切換不吃字，候選視窗跟著游標。
- **失敗**：任何吃字、重複、跑位，或候選視窗落後游標一個字以上。

### T-13 片段選單與挖空

- **怎麼做**：
  1. 空行行首用注音組字到一半（候選視窗開著）按 `/`；再切到全形打 `／`。
  2. 同一行先用注音打「中文」並選完字，打空白、打半形 `/h2` 按 Enter，接著用注音在標題裡打「安裝步驟」，選完字後按一次 `Cmd+Z`。
  3. 打 `/table` 按 Enter，在第一格用注音組字到一半按 Tab，選完字後再按 Tab 走完四格，最後再按一次 Tab。
  4. 捲到正文最下緣、讓游標停在視窗最底一行打 `/`。
  5. 打 `/link` 按 Enter 後按 `Esc`、再按 Tab；另一次在沒有選單也沒有挖空時按 `Esc` 接著按 Tab。
  6. 開啟 VoiceOver（`Cmd+F5`），空行打 `/`，用方向鍵往下移兩列，再按 `Esc`。
- **期望**：
  1. 組字中打 `/` 什麼都不發生：沒有選單、候選視窗留在原地、正文只多組字的字；全形 `／` 是一個標點、沒有選單。
  2. 選單只在選完字之後的半形 `/` 出現；標題另起一行落在「中文」下一行，落下後組字的候選視窗貼著游標、細記號不跳位；選完字後那個細記號消失；一次 `Cmd+Z` 只退掉「安裝步驟」，`## ` 還在。
  3. 組字中的 Tab 不跳格、不縮排、字不遺失；選完字後 Tab 依序跳到下一格，四格走完時沒有任何一行被縮排；再按一次 Tab 才縮排。
  4. 選單畫在游標上方，九列都看得見。
  5. 第一次 `Esc` 收掉挖空，接著的 Tab 是縮排、焦點不動；沒有選單也沒有挖空時，Vim 模式關著，`Esc` 後的 Tab 讓焦點離開編輯區。
  6. 選單一開，VoiceOver 念出有一份建議清單；每移一列就念出該列的名字（H1、H2、H3）；`Esc` 之後不再念選單。
- **失敗**：組字中出現選單或游標旁的畫面閃一下、候選視窗跑到角落、吃字、組字中的 Tab 跳格或縮排、一次 `Cmd+Z` 退掉整段、選單被畫面底部切掉、VoiceOver 沒念出選取的那一列。

## 發佈檢查清單

每次發佈前，以及**升級所用的 GUI 框架（Tauri）或編輯器元件（CodeMirror）之前**：

- [ ] 依賴版本鎖定：`Cargo.toml` 的 `[workspace.dependencies]` 用 `=` 釘住版本、`Cargo.lock` 已提交；`package.json` 用精確版本、`pnpm-lock.yaml` 已提交。
- [ ] 升級前在**舊版本**上跑完全部 13 項並記錄結果（基準）。
- [ ] 升級後在**新版本**上重跑全部 13 項；任何一項比基準差，就不升級。
- [ ] `pnpm check` 全綠。
- [ ] 內容安全政策沒有放寬（`src-tauri/src/content_security_policy.rs` 的測試會擋下與 `tauri.conf.json` 不一致的修改）。
- [ ] 預覽是死的：把一份惡意樣本（`<script>`、`onerror=`、`javascript:` 連結、`<iframe>`、`<svg>`、外部與 `data:` 圖片、`style` 屬性、表單元素）存成一篇文章，預覽打開時在開發者工具確認 `window.pwned` 仍是 `undefined`、網路面板沒有任何往外的請求。
- [ ] 預覽跟著系統深淺色：切換系統的深色／淺色模式，預覽底色、文字色與程式碼高亮一起換。收起預覽時編輯區佔滿空出的寬度。
- [ ] 視窗仍然拒絕導覽到外部頁面：在開發者工具裡執行 `location.href = "https://example.com/"`，以及點一個指向外部網站的連結，視窗都必須停在原頁、編輯區仍在。
- [ ] 刪除走系統垃圾桶：刪一篇文章、刪一個 workspace，兩者都出現在系統垃圾桶裡（不是永久刪除），而且拖得回原處；刪文章之後同一個 workspace 的 `images/` 一張圖都沒少。刪 workspace 的確認上的篇數與圖片數，與 Finder 裡數到的一致（`.DS_Store` 不算）。
- [ ] 貼上圖片：截一張圖在編輯區按 `Cmd+V`，`{workspace}/images/` 多一個 UUID 名字的 `.png`、正文多 `![](images/….png)`、預覽看得到那張圖，全程沒有對話框；按一次 undo 語法整段消失，檔案仍在（貼上不刪檔、刪不回來是已知行為）。貼一張 > 10MB 的圖，「正在存圖片…」出現與消失期間編輯區照樣能打字。
- [ ] 圖片位址只服務 vault：在開發者工具執行 `fetch` 不可行（`connect-src 'none'`），改為在預覽裡手寫 `![](images/../../x.png)`、`<img src="rustle://vault/.rustle/settings.json">`，都必須顯示不出來。
- [ ] 硬連結：本 App 新增的圖片檔一律「不存在才建立」，寫不進既有的硬連結；但 `images/` 本身若與 vault 外共用同一份 inode，符號連結解析看不出來——這一條仍未關閉，發佈前確認 vault 內沒有這種安排。
- [ ] 字體大小：指標在編輯區上用觸控板捏開一次，字大約大四分之一、手指在動時字一路跟著動（不跳格）；滑鼠按著 `Cmd` 滾一格，大約大三分之二；側欄、文章清單、按鈕與欄寬都不動，整個視窗沒有被縮放。組字中捏合照樣縮放、選字不被打斷；組字中按 `Cmd+0` 不重設。放大後游標畫在字上、捲動對得上；並排且兩邊大小不同時捲動一邊，另一邊跟到同一行。預覽放大後一、二級標題仍明顯大於內文，引言、程式碼、表格一起變大。重開 App 後兩邊各是上次的大小。
